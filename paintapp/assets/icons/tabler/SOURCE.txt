Tabler Icons (outline)
======================

Vendored from the Tabler Icons project: https://tabler.io/icons
Source repo:  https://github.com/tabler/tabler-icons
License:      MIT (see the LICENSE file in this folder)

These are the outline SVGs used by paintapp/icons.py for the layer-list
status badges. Each file is named after its Tabler icon and is referenced
by that name (the file stem) from paintapp/layers.py.

Currently vendored (Tabler 3.50.0)

To add another icon, drop its outline SVG here from

    https://cdn.jsdelivr.net/npm/@tabler/icons@<version>/icons/outline/<name>.svg

(keeping the format tag "outline" unless you deliberately want the "filled"
version) and reference "<name>" as the icon name where the badge is built.
Nothing else needs changing: paintapp/icons.py renders whatever is in this
folder. Bump the Tabler version above when you add or refresh icons so the
set stays pinned to one release.
